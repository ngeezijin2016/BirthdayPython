This is a fun program you can run when you want to show something to others or when someone has a birthday. When ran, it will print something
like:

 < < <
   | | |
  =======
  |     |
  |     |
  |_____|
Happy birthday to you
Happy birthday to you
Happy birthday to ..... oops, I don't know your name!
Happy birthday to you

You can tweak it, make it more fun yourself, but not copy.
